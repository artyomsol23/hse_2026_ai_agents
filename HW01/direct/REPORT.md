# Отчёт: мини-трекер учебных задач

## Что сделано

Реализовано автономное приложение без CDN, внешних библиотек и API-ключей.
Расчёты, фильтрация и валидация вынесены в `domain.mjs`; DOM и обработка событий — в `app.mjs`.
OpenSpec и папка `openspec/` не использовались и не создавались.

Файлы:

- `index.html` — разметка формы, фильтров, списка и сводки;
- `styles.css` — адаптивная вёрстка для ширины 390 px;
- `app.mjs` — состояние, рендеринг, обработчики формы и списка;
- `domain.mjs` — чистые функции: валидация, добавление, удаление, переключение, фильтр, прогресс;
- `tests/acceptance.test.mjs` — приёмочные тесты T1–T5 на `node:test`.
- `REPORT.md` — этот отчёт.

Данные хранятся в памяти. Необязательное сохранение в `localStorage` не реализовано.
Кнопка «Вернуть исходные данные» восстанавливает эталонные 3 задачи и фильтр «Все».

## Запуск

ES-модули требуют HTTP-сервера (через `file://` браузер может заблокировать импорт):

```sh
cd HW01/direct
python3 -m http.server 8000
# открыть http://127.0.0.1:8000/
```

Тесты:

```sh
node --test tests/acceptance.test.mjs
```

## Проверки интерфейса — выполнено

Выполнено в headless Chrome с эмуляцией viewport **390 × 844** (deviceScaleFactor 2), 30 проверок, все PASS:

- стартовые значения: 3 задачи, 8 ч, 2 ч, 25%, фильтр «Все»;
- поля «Название» и «Часы» подписаны; у кнопок и чекбоксов есть подписи/`aria-label`;
- прогресс размечен как `role="progressbar"` с диапазоном 0–100;
- T2: клик по «Практике» даёт 6 из 8 ч и 75%;
- T3: после сброса и фильтра «активные» видны только «Практика» и «Повторение», сводка остаётся 8 ч / 2 ч / 25%;
- T4: пустые и некорректные значения дают видимые ошибки рядом с полями, задача не добавляется, введённые значения сохраняются (проверены пустое название, пустые часы, `-1`, `1.25`, `24.5`);
- T4: значение `0.5` принимается, название обрезается по краям;
- T5: после удаления всех задач — 0 ч, 0%, без NaN/Infinity, показано пустое состояние; добавление новой задачи после этого работает;
- 390 px: нет горизонтального скролла и выхода элементов за viewport, в том числе с длинным неразрывным названием;
- нет JS-исключений и ошибок в консоли.
