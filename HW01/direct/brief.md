# Мини-трекер учебных задач

## Цель

Мини-трекер учебных задач на неделю.

## Результат

Автономное приложение без CDN,
внешних библиотек и API-ключей.

Файлы:
- index.html
- styles.css
- app.mjs
- domain.mjs
- tests/acceptance.test.mjs

## Данные задачи

id, title, hours, done.

## Исходные данные

| Задача | Часы | done |
|---|---:|---|
| Чтение | 2 | true |
| Практика | 4 | false |
| Повторение | 2 | false |

## Требования

R1. Добавление, удаление и переключение
done реально меняют данные.

R2. Название после trim непустое.
Часы — число от 0.5 до 24 с шагом 0.5.
Пустое значение не равно нулю.
Ошибка видна рядом с полем.
Данные формы сохраняются при ошибке.

R3. Прогресс = округление(
100 * сумма часов done / сумма часов всех задач).
Если задач нет — 0%, без NaN/Infinity.

R4. Фильтр: все / активные / готовые.
Фильтр влияет только на видимый список.
Итоговые часы и прогресс считаются
по всем задачам.

R5. При старте всего 8 ч, выполнено 2 ч,
прогресс 25%.
Если отметить «Практику» готовой —
6/8 и 75%.

R6. Интерфейс читаем на ширине 390 px,
без горизонтального скролла.
Поля и кнопки подписаны.

## Приёмочные проверки

T1. Исходный пример.
Ожидание: 3 задачи, 8 ч всего,
2 ч выполнено, прогресс 25%.

T2. Отметить «Практику» выполненной.
Ожидание: 6 из 8 ч, прогресс 75%.
Данные и интерфейс изменились.

T3. Восстановить исходные данные.
Включить фильтр «активные».
Ожидание: видны «Практика» и «Повторение».
Общий прогресс остаётся 25%.

T4. Проверить пустое название, пробелы,
пустые и отрицательные часы.
Дополнительно проверить границы 0.5–24
и шаг 0.5.
Ожидание: некорректная задача не добавляется,
ошибка видна, значения формы сохраняются.

T5. Удалить все задачи.
Ожидание: 0 ч, 0%, без NaN/Infinity.
Интерфейс продолжает работать.

Перед независимыми сценариями
восстановить исходные данные.

## Тестирование

Автоматизировать расчёты 25%/75%,
независимость метрик от фильтра,
валидацию и пустое состояние через node:test.

Форму, кнопки, текст ошибок и ширину 390 px
проверить вручную.

Фактически выполненные проверки
отделять от предложенных.
Непроведённые проверки обозначать NOT RUN.

## Необязательное улучшение

Сохранение задач в localStorage.
При недоступном хранилище показать сообщение
и продолжать работу в памяти.
